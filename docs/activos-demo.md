# Activos de la demo

- `hero-concept.webp`: composición conceptual generada para el proyecto, exportada a WebP a 1680 x 946, aproximadamente 77 KB.
- `collection-concept.webp`: composición cenital conceptual generada para el proyecto, WebP a 1000 x 1000, aproximadamente 107 KB.
- No representan trabajos vendidos ni productos fotografiados de JazAr. La interfaz los identifica como conceptos; sustituirlos por fotografías autorizadas de cada producto.
- No se reconstruyó el logotipo de Facebook. El nombre tipográfico de la demo es temporal hasta recibir el archivo original.
- Space Grotesk y Manrope: archivos WOFF2 latinos variables descargados de Google Fonts, licencias OFL incluidas en `static/fonts/licenses/`.
- GSAP/ScrollTrigger 3.15.0 y Lucide 0.468.0: copias locales versionadas, con avisos de licencia en `static/vendor/licenses/`.
- Se conserva desplazamiento nativo, sin Lenis ni Three.js en la carga de esta demo.
